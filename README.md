# Portafolio Rafael Martín González Mojica — v4

## Archivos incluidos
- `index.html` — sitio web del portafolio.
- `hoja-de-vida-rafael.pdf` — hoja de vida real, renombrada para coincidir con los enlaces del sitio.

## Publicar en GitHub Pages
1. Descarga y descomprime este ZIP.
2. Abre https://github.com/rafaelgonzalezm507-byte/portafolio
3. Entra en **Add file → Upload files**.
4. Sube `index.html` y `hoja-de-vida-rafael.pdf` a la raíz del repositorio.
5. Si GitHub pregunta si quieres reemplazar `index.html`, confirma.
6. Pulsa **Commit changes**.
7. Comprueba **Settings → Pages**: `Deploy from a branch`, `main`, `/(root)`.
8. Espera unos minutos y abre https://rafaelgonzalezm507-byte.github.io/portafolio/

## PDF
El HTML ya apunta a `hoja-de-vida-rafael.pdf` para el visor integrado, el enlace de apertura y el botón de descarga. No hace falta cambiar el nombre ni editar las rutas.

## Retrato binario
La foto no se incluye separadamente en este ZIP porque ya forma parte del PDF, pero el efecto de retrato del sitio requiere `perfil.jpg` como archivo de imagen independiente si se decide usar la ruta local. Puedes exportar la foto del CV como JPG y subirla como `perfil.jpg`, o mantener la URL externa si funciona.

## Tecnologías
HTML5, CSS3 y JavaScript nativo. El globo de nodos y el fondo de partículas se dibujan con Canvas; etiquetas y paneles 3D usan CSS. La terminal es una simulación visual y no ejecuta comandos.
